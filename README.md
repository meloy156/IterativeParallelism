## 🎯 О проекте

Реализация интерфейсов `ScalarIP` и `NewScalarIP` — параллельные версии скалярных операций над списками. Каждый метод разбивает список на `threads` кусков, обрабатывает их в отдельных потоках и сливает результаты в один глобальный ответ.

Проект демонстрирует:

- работу с потоками (`Thread`, `join`, `interrupt`);
- синхронизацию без блокировок (`AtomicInteger`, `AtomicLong`);
- защиту от гонок через `synchronized`;
- корректную обработку `InterruptedException`;
- разбиение задачи на подзадачи (*divide and conquer*).

---

## ✨ Возможности

| Метод | Описание | Возвращает |
|:------|:---------|:-----------|
| `argMax` | Индекс первого максимума | `int` |
| `argMin` | Индекс первого минимума | `int` |
| `indexOf` | Индекс первого элемента, удовлетворяющего предикату | `int` (`-1`, если нет) |
| `lastIndexOf` | Индекс последнего элемента, удовлетворяющего предикату | `int` (`-1`, если нет) |
| `sumIndices` | Сумма индексов элементов, удовлетворяющих предикату | `long` (`0`, если нет) |

Все методы имеют **две версии** — без шага и с параметром `step`.

Исходный список: [3, 1, 4, 1, 5, 9, 2, 6]
threads = 4, step = 1
